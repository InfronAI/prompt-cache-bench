# Data

This directory contains the public telemetry exports for `openai/gpt-5.4-mini`.

- `benchmark_pairs.csv`: filtered A/B pair dataset.
- `benchmark_requests.jsonl`: request-level telemetry.
- `summary.json`: aggregate metrics used by reports and charts.
- `records_excluded.json`: excluded-record audit.

The source dataset is the built-in `business_representative` benchmark corpus.
