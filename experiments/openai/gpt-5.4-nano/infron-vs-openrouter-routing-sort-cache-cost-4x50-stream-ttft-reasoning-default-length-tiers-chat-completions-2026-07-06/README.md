# openai/gpt-5.4-nano A/B Benchmark

This directory contains the published Infron vs OpenRouter prompt-cache benchmark for `openai/gpt-5.4-nano`.

- Design: 4 groups x 50 rounds, streaming Chat Completions, default reasoning/thinking behavior, prompt-length tiers, `/v1/chat/completions` only.
- Retained paired samples: 790
- Request-level observations: 3160
- Excluded records: 20
