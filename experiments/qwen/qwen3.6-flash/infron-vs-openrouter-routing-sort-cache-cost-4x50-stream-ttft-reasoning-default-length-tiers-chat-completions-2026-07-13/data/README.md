# Data

Public benchmark datasets for the `qwen/qwen3.6-flash` Infron vs OpenRouter A/B benchmark.

- `benchmark_pairs.csv`: paired A/B metrics, 800 valid pairs plus header.
- `benchmark_requests.jsonl`: request-level telemetry, 3200 request rows.
- `summary.json`: aggregate metrics used by the reports.
- `records.json`: filtered structured records used for analysis.
- `records_excluded.json`: excluded-record audit; this run excluded 0 records.
