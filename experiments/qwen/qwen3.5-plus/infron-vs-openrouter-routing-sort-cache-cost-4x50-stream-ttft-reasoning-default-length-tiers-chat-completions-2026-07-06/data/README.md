# Data

Benchmark datasets for `qwen/qwen3.5-plus` run `routing_sort_cache_cost_ab_3x40_repeat_1783297630`.

- `summary.json`: aggregate metrics and experiment metadata
- `benchmark_pairs.csv`: paired A/B dataset used for route-level statistics
- `benchmark_requests.jsonl`: request-level telemetry dataset
- `records.json`: filtered structured records
- `records_excluded.json`: excluded-record audit
- `records_incomplete.json`, `records_unequal_input_tokens.json`, `records_anomalous_usage.json`: exclusion breakdowns
