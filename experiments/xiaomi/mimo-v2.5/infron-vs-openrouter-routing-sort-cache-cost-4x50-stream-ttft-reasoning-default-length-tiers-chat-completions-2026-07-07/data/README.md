# Data

Benchmark datasets and request-level telemetry for the `xiaomi/mimo-v2.5` 4x50 streaming Chat Completions A/B experiment.

Key files:

- `summary.json` - aggregate metrics and report inputs.
- `benchmark_pairs.csv` - strict A/B paired benchmark rows.
- `benchmark_requests.jsonl` - request-level telemetry.
- `records.json` - filtered structured records.
- `records_excluded.json` - excluded-record audit.
